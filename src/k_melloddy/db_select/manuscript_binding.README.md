# Explicit author-manuscript identity binding

Inputs: `evidence_review.manuscript_identity_bindings` with actual PDF and official metadata evidence IDs, exact manuscript title/title quote and explicit reviewer rationale. Only unfinished reviews opting into this check are affected. Original CSV, canonical bibliographic title/DOI and native captures remain unchanged.

Algorithm: validate complete HTTP200 PDF and Europe PMC search-response bytes/hashes; require one MED PMID/DOI/canonical-title match and its explicit free PDF URL matching the actually downloaded URL. Re-extract the complete unencrypted PDF with pypdf and compare to captured text. Require the quoted manuscript title on its first page region, the same complete primary title before the colon, and every official author surname in the opening text. Reject a conflicting front-page DOI. A changed editorial subtitle is retained verbatim; matching a few keywords, similar authors or an unrelated PDF URL is insufficient.

Outputs/states/audit: append a deterministic derived full-text identity record with parent ID, unchanged bytes/text/hash/HTTP metadata, original failed identity checks and the explicit binding. Its transport states that no new request occurred. The original mismatch record remains visible. This verifies article identity only; reading Methods/Results/Data Availability, supplementary/repository review and scientific eligibility are still required. No automatic inclusion, dataset or count is created.

Units/limits: SHA-256 and bytes, at most three bindings; 1 MiB bibliographic response, 8 MiB PDF, 64 pages, 250,000 text characters. Author/title checks use the first 7,000 characters and conflicting DOI check the first 2,500. Source availability must explicitly be free; no credentials, paywall or CAPTCHA bypass. Boundaries are conservative and can leave a valid manuscript unresolved.

Retries/resume: deterministic offline check of immutable captures; no network request or finalized-record replay. Failed binding stops answer validation and retains the unfinished paper. A new response/selection has a new immutable request/answer. Commands/tests: `python -m pytest tests/test_manuscript_binding.py tests/test_full_workflow.py tests/test_verified_select.py -q`. Offline fixtures test exact official link, PMID/DOI/title, author names, conflicting DOI, changed payloads and original preservation. Limitations: only explicitly linked Europe PMC free PDF author versions with a colon-separated matching primary title; changed primary titles, absent authors, scanned/encrypted documents and unlinked files need separate verification.
