# Human review of captured evidence

`apply_captured_reviews(engine, run, campaign, path)` consumes an explicit reviewer-authored JSON submission. It checks the original campaign scope, PMID, exact base revision, original Collect hash and pending-attempt cap. It never generates a scientific verdict. Inputs include a reviewer note, optional validated proposal, hash-checked additional HTTP capture files, precise access-classification corrections and optional visual-review page records. Image pages must match hashes and actual image URLs in an identity-matched parent article response. Additional captured responses keep their original timestamps and statuses.

The operation appends a separate revalidation history and SQLite revision for each paper, then refreshes cumulative JSON and PRISMA. The captured-review hash makes replay idempotent, including failure after a paper commit. Original HTTP records, old revisions and earlier decisions remain immutable. `network_repeated=false` distinguishes this human evidence review from another network pass; truly additional network captures retain their own GET logs. Missing or changed evidence fails validation; it is not automatically excluded.

States and units: reviewed or blocked verification per paper; HTTP attempts remain separately counted. A visual review can establish full-text access and inspected sections, but cannot establish dataset availability or complete a repository survey. Cited access constraints describe the service and version actually observed, not all historical datasets. P01 needs a concrete clue and unresolved route; P02 retains the original alternative-route checks; P03/P04 need material/file citations. Inclusion/exclusion still uses all existing gates. Global LLM configuration is unchanged.

Usage from the workspace Python environment: import `VerifiedSelector` and `apply_captured_reviews`, instantiate the engine for `projects/Liver/DB_Select`, pass the parent run, campaign and saved review JSON, and close the engine. Then rerun the same campaign export command to regenerate the full 100-paper workbook. Do not reset attempts or edit capture hashes to bypass stale-review checks.

Tests: `python -m pytest -q tests/test_revalidation_campaign.py`. Synthetic coverage checks separate attempt accounting and idempotent replay. Limits: reviewers must actually inspect the cited content; image verification proves provenance and integrity, not the scientific correctness of an annotation. OCR-only evidence can contain transcription errors. Unresolved original files, supplements and reuse permissions remain pending.
